#  Personal Finance Dashboard

A responsive personal finance dashboard built with **HTML, CSS, and JavaScript**. It allows users to track income and expenses, manage transactions, visualize spending, and export their financial data.

##  Features

- Add income and expense transactions
- Edit existing transactions
- Delete transactions
- Automatic balance calculation
- Income and expense summaries
- Search transactions
- Sort transactions
  - Newest
  - Highest amount
  - Lowest amount
  - A-Z
- Transaction categories
- Transaction dates
- Spending by category
- Monthly spending chart
- Export transactions as CSV
- Dark / Light mode
- Persistent data using Local Storage
- Responsive dashboard interface

##  Built With

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage
- Chart.js
